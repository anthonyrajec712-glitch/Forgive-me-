# Sorry Anneyy

A one-page apology website. Everything is in `index.html` (photos included), so no build step is needed.

## Put it online with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to it.
3. Go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, then save.
4. After a minute your site appears at `https://<your-username>.github.io/<repo-name>/`.
